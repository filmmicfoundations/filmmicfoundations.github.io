# Filmmic Foundations — Film Research Archive

This is the complete website, with Filmmic Foundations as the visible database name throughout.

## Install

Upload the CONTENTS of this folder to the ROOT of the GitHub repository `filmsforever/filmsforever`. The root of the repository must directly contain `index.html`, `style.css`, `favicon.svg`, `favicon.ico`, and the `mindglassprocedure` folder. Do not upload the ZIP itself or nest these files in another folder. Replace the old root `index.html` and the old `mindglassprocedure/index.html`.

After GitHub Pages deploys, check the source of the live homepage for `<title>Filmmic Foundations | Film Research Archive</title>`. If the source still shows the old branding, GitHub is serving the old file. Refresh with Cmd+Shift+R or use a private window.

The address `https://filmsforever.github.io/filmsforever/` still includes `filmsforever` because it is the GitHub account/repository name, not the visible website name.
