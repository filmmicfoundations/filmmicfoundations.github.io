# Mindglass Procedure — Critical Film Analysis

A standalone, static website presenting a critical analysis of the 2025 short film *Mindglass Procedure*.

## Publish on GitHub Pages

Upload `index.html`, `style.css`, `paper.pdf`, and the complete `assets/` folder to the **root** of your public `filmsforever/mindglassprocedure` repository. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`.

The website will appear at https://filmsforever.github.io/mindglassprocedure/

The PDF is the source of the article text. The website includes a disclosure of AI assistance and no peer-review claim.
