Research to article.

Prepare a research PDF, an approved cover image, and editorial notes for a publication draft in the style of Mindglass Procedure. The files stay on your device until you upload the prepared package to GitHub.

Prepare your submission

A searchable PDF and one licensed cover image are required. You can also include extra film stills and notes to guide the analysis.

Lowercase letters, numbers and hyphens. Your future article URL will end in /your-name/.

Don't include passwords or private personal information. Check that you have permission to publish images and research materials.

Your submission is ready

Your ZIP contains paper.pdf, notes.md, and your images in assets/. The package was created locally in your browser.

  1. Click Upload to GitHub and upload the downloaded your-name.zip to submissions/inbox/. Commit the upload.
  2. In GitHub, open Actions → Draft article from research PDF → Run workflow.
  3. Enter the article URL name you chose above, then run the workflow. It uses the API key stored in GitHub Secrets.
  4. Open the generated pull request and review every claim, reference, image, and diagram before merging.
Upload to GitHub

GitHub's browser uploader has a 25 MB per-file limit. For larger submissions, use GitHub Desktop to add the ZIP to submissions/inbox/. GitHub Pages cannot directly accept uploads or securely call an AI API.

Before you submit

For a substantive article, the paper should include a clear thesis, evidence from specific scenes, properly identified sources, and permission to use the supplied visuals. The builder follows the source material; it does not invent research or film stills.

Download the research questionnaire

Drafts require a manual review and approval. AI API usage may incur costs. Only repository collaborators with appropriate permissions can run the workflow.
