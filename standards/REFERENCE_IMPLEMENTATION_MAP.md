The included `site_baseline.zip` is a **working historical snapshot**, not a guarantee of live deployment. Latest user-provided repository/source ZIP overrides it. Never blindly overwrite newer files.

## Files a NEW article may contain

```
film-slug/
  index.html                      # complete styled article using shared assets
  article.json                    # structured publication metadata
  preview.json                    # six still images and captions
  style.css                       # only film-specific styles, if needed
  Film_Title_Film_Analysis.pdf    # entire text + inline citations + images
  build_pdf.py                    # optional: reproducible HTML-derived PDF
  assets/
    film-slug-shot-name.jpg
    film-slug-shot-name-640.jpg
    ...                           # 7–15 genuine stills with variants
  research/
    sources-ledger.json           # 10+ real sources and claim mapping
    scene-log.json                # verified moments/timestamps
    figure-plan.json              # positions/timestamps/captions/rights
```

`article.json` supplies film title/year, publication date, tags, cover, authoring info (organization only). `preview.json` supplies **six stills** and captions. `index.html` must include shared Settings/navigation scripts and film article action menus. Existing archive builder automatically updates home/search/feed/related links after deployment.

## Browser acceptance, not just program output

1. On home: card count rises by exactly one, other cards remain unchanged, preview opens with 6 genuine frames, layout/sort/search/theme controls work.
2. In new article: cover image, title, side TOC, citations/references, 7–15 authentic stills, non-clickable diagrams, image viewer controls, Watch the Film (link/embedded if available), PDF button, related section LAST, both modes and mobile.
3. PDF: compare rendered first page, TOC, body examples, all figure order and reference links to Mindglass and HTML.
4. Portal offline dry run: after selecting ZIP, automatic file review starts; path `film-slug/index.html` remains nested, and **root `index.html` is absent from ZIP**.
5. Live deployment only after operator's approval and GitHub Actions success; verify direct URL `/film-slug/` and four-plus-card homepage.
