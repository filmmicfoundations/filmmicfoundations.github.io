# Real release lessons: avoid repeating known regressions (Edition 3.0)

This site has previously needed repair after articles were prepared without sufficient integrated testing. These are **technical lessons**, not film-writing examples.

1. **Wrong ZIP shape replaced homepage.** A ZIP containing a nested `index.html` was once mishandled. Confirm every archive member starts with `film-slug/` before handoff, and simulate Developer Portal inspection. The archive's root MUST NOT contain `index.html`. A ZIP with `film-slug/assets/` and `film-slug/index.html` is an article-only ZIP, not an entire site. The platform may regenerate homepage metadata after GitHub Pages deployment.
2. **A film-still article had missing images / external hosts.** Store real local JPEG images and 640-width variants, with paths relative to the article directory, intrinsic dimensions and exact filenames. Browser-test image naturalWidth >0 and viewer opening; report blocked film-download streams truthfully. Film-preview thumbnails should never be only diagrams.
3. **Article PDF drifted from Mindglass.** Match first-page order, information table, cover image and contents. Generate PDF from article HTML/shared manuscript and inspect all pages. Don't abridge to squeeze figures onto pages. Keep all figures ordered with adjacent text, not moved into unrelated appendices.
4. **Citation numbers clustered at paragraph ends.** Citations follow particular evidenced claims inside paragraphs in BOTH HTML and PDF; the new AI must edit citation positions and preserve the source IDs, not merely move their CSS visually. PDF contents/method page is plain text; body reference markers and URLs remain linked.
5. **Duplicate figure images / distorted thumbnails.** Every 7–15 stills should support a different analytical point. Film frame integrity matters more than volume. Do not count re-crops of the same image as separate frames. Diagrams are original nonclickable HTML; PDF can render them as readable diagrams, not inert decoration.
6. **Broken viewer centering / sticky navigation overlays.** Avoid competing `inset`, `transform`, or scrollbar-offset rules. Test actual modal bounding-box centers after entrance animation in 1365 px desktop, 390 px portrait and narrow landscape, in light and dark modes. Ensure backdrop dims menus and scroll/focus behave correctly.
7. **Cached settings code hid new UI / unwanted palettes.** The requested final identity is TEAL ONLY with Light/Dark/System settings. Don't revive old optional Accent Color settings, even if an earlier abandoned CSS file mentions them. For legitimate shared code updates, cache-bust changed scripts and test computed behavior across all pages.
8. **ZIP inspection failed from cache files.** Never include `__pycache__/`, `.pyc`, `.DS_Store`, `node_modules`, `.git`, scratch screenshots or secrets. The preflight, package utility and ZIP integrity check are separate gates.
9. **Article ZIP uploaded but card missing.** A portal upload is only selection and review, not publication. Verify approval, commit, GitHub Pages workflow and live card/direct `/film-slug/` path. Do not claim live success from a local build.
10. **Old guide statements conflicted with later decisions.** Follow v3 contract and source current code first; do not assume every statement in older example Markdown controls current publication format.

The AI should maintain a release QA report noting which of these regression scenarios were checked.
