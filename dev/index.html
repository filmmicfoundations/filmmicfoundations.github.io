04 / GITHUB CONNECTION

Authorize publishing.

GitHub Pages cannot securely modify a repository with only a page password. For live updates, provide an authorized fine-grained GitHub personal access token for this session. It is kept in memory and never saved to this website, but a public static-page client is not a substitute for a secure server.

Create a token limited to this repository with Contents: Read and write, and Actions: Read for the deployment history. Updating workflow files may need additional permissions. Tokens are not stored in localStorage, cookies, or URLs.
