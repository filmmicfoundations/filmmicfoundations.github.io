# New research submissions

Create `submissions/your-article-slug/` with:

- `paper.pdf` — a searchable PDF with the full research paper and bibliography.
- `notes.md` — completed research questionnaire or supplemental facts and citations.
- `assets/cover-image.webp` — a publication-cleared cover still. Additional cleared images are welcome.

Then run **Actions → Draft article from research PDF → Run workflow**, entering `your-article-slug`.
The workflow creates a **pull request** for review; it does not publish the draft directly.

Important: the `submissions/` folder is part of the public GitHub repository. Do not upload private manuscripts, personal information, or unlicensed assets unless you are comfortable with them being public. If privacy matters, use a private repository for submissions and adapt the workflow.
